# MoMoMooD Business Performance Dashboard

## Overview
A Power BI dashboard built to analyze restaurant sales and performance.

## Key Metrics
- Total Revenue: ₹38K
- Total Profit: ₹11K
- Total Orders: 484

## Features
- Revenue Trend Analysis
- Profit Trend Analysis
- Online vs Offline Revenue Comparison
- Customer Conversion Funnel
- Competitor Comparison

## Tools Used
- Power BI
- Microsoft Excel
